Entry for the [make.fun bounty](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5): one dad joke, at most 200 characters, that earns the bigger groan.

## The joke

> My wife caught me counting the fence posts and asked what I was doing. I said, 'I'm just trying to picket up where I left off — the neighbors think I'm board.'

## What it does

`main.py` (Python 3.13, standard library only) writes the joke line to `/output/entry.txt`. It creates `/output` if needed, asserts the line is 1–200 characters, and the output is deterministic — byte-identical on every run.

## Run it

```sh
python3 main.py
```

Then read `/output/entry.txt`.
